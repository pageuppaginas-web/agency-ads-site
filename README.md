# Agency Ads — site institucional

Este repositório contém uma cópia estática do site da Agency Ads. Os arquivos principais são `index.html`, `styles.css`, `script.js` e `assets/agency-ads-logo.png`.

## Visualizar localmente

Com Python 3 instalado, execute na raiz do repositório:

```bash
python3 -m http.server 8000
```

Depois acesse `http://localhost:8000`.

O formulário prepara uma mensagem com as respostas e abre o WhatsApp `+55 77 98818-0629` para revisão e envio pelo visitante. O site não armazena os dados do formulário.

O manifesto `manus-routes.json` é mantido para referência do projeto Manus; a navegação estática do site funciona sem ele.
